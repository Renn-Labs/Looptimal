# Verified code change

Use this starter when a bounded defect can be reproduced and independently checked.

1. Bind each immutable `loop://` reference to a real local loop.
2. Replace reviewer identities and expected evidence with actors available in your environment.
3. Replace the final test command with the smallest command that proves the outcome.
4. Keep `execution.mode` disabled until a separate runtime and authority review exist.

Structural GREEN is not proof that the code change has run or passed.
